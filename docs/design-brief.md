## 0. 한 줄 요약

**네이버 CPC 광고로 들어온 방문자를 "생산 문의"로 전환시키는 B2B 리드젠 사이트**입니다.
브랜드 인지도용 사이트가 아니라, 문의 폼 제출이 유일한 성과 지표입니다.

- 방문자: 건강기능식품 브랜드를 만들려는 **초기 창업자**와 확장 중인 기업 담당자
- 목표 행동: 상단/하단 CTA → `생산 문의` 폼 제출
- 트래픽: **모바일 비중 높음** (검색광고 유입). 모바일이 1순위입니다.
- 언어: 한국어(기본) / 영어 / 중국어 — 같은 레이아웃을 3개 언어가 공유

## 1. 디자인 방향

### 톤
의약품·식품 제조업의 **신뢰감**이 최우선입니다. 화려함보다 정돈됨, 여백, 또렷한 위계.
"공장을 믿고 맡길 수 있는가"를 시각적으로 답해야 합니다.

### 컬러 토큰 (현재 값 — 변경 제안 환영)

| 역할 | 토큰 | 값 |
|---|---|---|
| 브랜드 메인 | `brand-600` | `#127a58` (딥 그린) |
| 브랜드 진한 | `brand-700` / `brand-900` | `#0f6148` / `#0d4032` |
| 브랜드 옅은 배경 | `brand-50` | `#eefaf4` |
| 포인트 | `accent-500` | `#f0a202` (앰버 — HOT 배지에만) |
| 본문 텍스트 | `ink-900` | `#1b1d21` |
| 보조 텍스트 | `ink-500` | `#6d7480` |
| 테두리 | `ink-200` | `#dcdee1` |
| 섹션 배경 | `ink-50` | `#f7f8f8` |

### 타이포
- 국문 `Noto Sans KR` (400 / 500 / 700 / 800)
- **한글은 단어 단위 줄바꿈**(`word-break: keep-all`)이 적용돼 있습니다. 짧은 문장이 어색하게 끊기지 않도록 여유 폭을 주세요.
- 제목은 3~5단어에서 줄바꿈되는 경우가 많습니다 (예: `당신의 아이디어를 / 가장 빠르게 제품으로`)

### 모양
- 카드 라운드 `1rem`, 버튼 `0.5rem`
- 그림자는 최소한 — 테두리(`ink-200`)로 구분하는 것이 기본
- 라이트 테마 전용 (다크 모드 없음)

## 3. 공통 요소

### 헤더 (sticky)
- 높이 데스크톱 80px / 모바일 64px, 반투명 흰색 + 블러
- 좌: 로고 · 중: 네비(드롭다운 2단) · 우: 언어 전환(KR/EN/CN) + `생산 문의` 버튼
- 모바일: 햄버거 → 전체 메뉴 패널(대분류는 소제목, 하위 항목 나열)

### 모바일 하단 고정 바 ★ 중요
화면 하단에 항상 붙어 있는 2분할 바. **전환율을 좌우하는 요소**입니다.

```
┌────────────────┬────────────────┐
│ 📞 031-000-0000 │  💬 생산 문의   │  ← 우측은 브랜드 그린 채움
└────────────────┴────────────────┘
```

### 푸터
- 좌: 회사명 / 대표이사 / 사업자등록번호 / 주소 / 대표전화 / 팩스
- 우: 전체 메뉴 링크 (2~3열 그리드)
- 하단: 저작권 · 이용약관 · **개인정보처리방침(굵게)**

### 하단 CTA 배너 (모든 하위 페이지 공통)
브랜드 그린 배경 + 흰 버튼.
`제품 아이디어만 있으면 충분합니다` / `담당자가 영업일 기준 1일 이내에 연락드립니다`

## 4. 페이지별 구성

### 4-1. 홈 `/` ★ 최우선

광고가 직접 떨어지는 페이지입니다. **첫 화면에서 "무엇을 하는 회사이고, 어떻게 문의하는지"가 끝나야** 합니다.

| # | 섹션 | 내용 |
|---|---|---|
| 1 | **히어로** | 배지 `건강기능식품 OEM·ODM·CDMO` / 제목 `당신의 아이디어를\n가장 빠르게 제품으로` / 설명 2줄 / 버튼 2개(`1분 만에 견적 문의`, `보유 원료 보기`) / 우측에 **숫자 카드 4개** (업력 26년, CCM 16년 연속, 고객 만족도 98%, 누적 생산 3,200+) |
| 2 | **서비스 5종** | 아이콘 카드 5개 — OEM / ODM / CDMO / 개인맞춤형 / 펫. 각 카드는 문의 페이지로 연결 |
| 3 | **HOT 트렌드 원료** | 원료 카드 최대 8개 (썸네일 4:3 + 분류 배지 + 이름 + 요약 3줄). 우상단에 `보유 원료` 전체보기 버튼 |
| 4 | **제형 · 포장** | 2열. 좌: 제형 7종 칩(환/경질캡슐/연질캡슐/젤리/액상/분말/정제), 우: 포장 6종 칩(멀티팩/이중제형/병포장/액상포장/PTP/스틱포장) |
| 5 | **인증** ★ | **다크 배경 섹션**(`ink-900`). GMP·HACCP·ISO 9001/14001/22000/45001/50001·CCM 로고 또는 체크 아이콘 그리드 |
| 6 | **Priority Service** | 카드 4개 — 패키지 디자인 / 온라인 유통 연계 / 특허 전략 / 펀딩 지원 |
| 7 | **최근 접수된 문의** | 사회적 증거. 리스트 6줄 (유형 배지 · 제형 · 날짜). **개인정보는 표시하지 않음** |
| 8 | **최종 CTA** | 브랜드 그린 배너 |

> 섹션 5는 의도적으로 다크입니다. 페이지 중간에 시각적 앵커를 만들어 "인증받은 공장"을 각인시키는 역할입니다.

### 4-6. 생산 문의 `/inquiry` ★★ 최우선 — 전환 페이지

**여기가 사이트의 목적지입니다.** 이탈을 최소화하는 폼 디자인이 핵심입니다.

3개 섹션으로 나뉜 단일 페이지 폼:

**① 연락처 정보** (2열)
- 담당자명 `필수` / 회사명 `선택` / 연락처 `필수` / 이메일 `선택`

**② 제품 정보**
- 문의 유형 — 셀렉트 (OEM / ODM / CDMO / 개인맞춤형 / 펫)
- 희망 제형 — **칩 다중선택 7개** (환·경질캡슐·연질캡슐·젤리·액상·분말·정제)
- 희망 포장 — **칩 다중선택 6개**
- 예상 수량 / 예상 예산 / 희망 납기 — 3열 셀렉트·날짜
- 상세 문의 내용 — 텍스트영역
- **첨부파일** — 최대 3개, 각 5MB (pdf·png·jpg·webp·docx·xlsx·hwp). 선택 즉시 업로드되고 파일명·크기·삭제 버튼이 있는 리스트로 표시

**③ 동의**
- 회색 박스 안: 개인정보 수집·이용 동의 `필수` + 수집 항목/목적/보유기간 안내 3줄
- 구분선 아래: 마케팅 수신 동의 `선택`

**제출 버튼** — 모바일에서는 전체 폭

> 선택 칩(제형/포장)은 체크되면 그린 테두리 + 연한 그린 배경 + 굵은 글씨로 바뀝니다.
> 필수 항목은 라벨 옆 빨간 `*`, 오류는 입력창 아래 빨간 텍스트.

**완료 `/inquiry/complete`**
- 가운데 정렬. 큰 체크 아이콘 → `문의가 정상 접수되었습니다` → 안내 문구 → `홈으로 돌아가기`
- 광고 전환 태그가 발화하는 지점입니다

## 5. 반드시 지켜야 할 것

1. **모바일 우선.** 광고 유입의 대부분이 모바일입니다. 하단 고정 CTA 바 높이(약 56px)만큼 본문 하단 여백이 필요합니다.
2. **3개 언어 공용 레이아웃.** 영문·중문은 같은 문장이 **1.3~1.6배 길어집니다.** 버튼·배지·카드가 2줄이 되어도 깨지지 않아야 합니다.
3. **빈 상태 설계 필수.** 오픈 초기에는 원료·포트폴리오·게시물이 적고 이미지가 없는 항목이 많습니다. 플레이스홀더와 "등록된 항목이 없습니다" 상태를 함께 디자인해 주세요.
4. **텍스트 길이 가변.** 원료 요약·제품 설명은 관리자가 입력하므로 길이가 제각각입니다. 3줄 말줄임을 전제로 해주세요.
5. **접근성** — 포커스 링, 본문 바로가기 링크, 색상만으로 정보를 전달하지 않기.

## 8. 참고

- 현재 구현: Next.js + Tailwind CSS v4. **디자인 토큰(색·간격·라운드)을 CSS 변수로 관리**하므로, 팔레트를 바꾸시면 코드 반영이 간단합니다.
- 콘텐츠(원료·포트폴리오·게시물)는 관리자에서 등록하며 이미지도 업로드됩니다. 목업의 텍스트/이미지는 예시로만 봐주세요.
- 심볼: 공장 + 새싹 마크를 브랜드 그린 타일에 흰 글리프로 적용했습니다 (`src/app/icon.svg`).
  Stitch가 준 로크업(`design/stitch/헬씨팜바이오-파비콘.png`)은 파란색이고 워드마크가
  포함돼 16px에서 읽히지 않아, 마크만 따와 다시 그렸습니다.
  원본 로크업은 `public/brand/logo-lockup.png` 에 보관 중입니다.
