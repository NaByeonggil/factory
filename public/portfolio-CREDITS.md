# 포트폴리오 카드 이미지 출처

제품 이미지는 관리자 업로드와 같은 경로(storage/uploads/pub/…)에 저장되어
DB의 Product.imageUrls 로 연결됩니다. 저장소 파일은 git에 포함되지 않으므로,
운영 환경에서는 관리자 화면에서 다시 업로드해야 합니다.

Pexels 라이선스(상업적 사용 무료 · 출처 표기 의무 없음 · 이미지 자체의
재판매/재배포 금지)이며, 브랜드·로고가 보이는 컷은 제외했습니다.
